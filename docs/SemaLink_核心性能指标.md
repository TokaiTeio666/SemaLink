# SemaLink 核心性能指标建议

> 本文档中的数值用于定义 **SemaLink 竞赛原型的性能目标与验收标准**，属于建议指标，并非 HarmonyOS 官方标准，也不是当前项目已经实测得到的结果。

## 核心性能指标

| 指标 | MVP 合格线 | 竞赛展示目标 | 测量方式 |
|---|---:|---:|---|
| 设备路由 Top-1 准确率 | ≥ 75% | **≥ 85%** | 最可能有答案的设备是否排在第一位 |
| 设备路由 Top-2 召回率 | ≥ 90% | **≥ 95%** | 正确设备是否进入候选设备前两名 |
| 首结果延迟 P50 | ≤ 1.5 s | **≤ 800 ms** | 从用户提交查询到收到首个 L1 摘要或标题 |
| 首结果延迟 P95 | ≤ 3 s | **≤ 1.5 s** | 95% 查询的首结果返回延迟 |
| 任务完成延迟 P50 | ≤ 3 s | **≤ 2 s** | 从用户提交查询到 TSF 状态变为 `ENOUGH` |
| 单任务通信量 | ≤ 256 KB | **≤ 64 KB** | 包含查询请求、证据、反馈及协议开销 |
| 相比完整文件传输节省比例 | ≥ 60% | **≥ 85%** | 与直接传输完整文件的基线方案比较 |
| 原始文件离站比例 | ≤ 10% | **≤ 5%** | 触发 L3 完整文件传输的任务占比 |
| L1/L2 即可完成比例 | ≥ 80% | **≥ 90%** | 无需传输完整文件即可完成的任务比例 |
| 早停成功率 | ≥ 80% | **≥ 90%** | 证据已经充分后，系统正确停止继续传输 |
| 错误早停率 | ≤ 10% | **≤ 5%** | 证据不足时却错误判断为 `ENOUGH` 的比例 |
| 查询任务成功率 | ≥ 90% | **≥ 95%** | 最终找到正确证据并成功返回结果的任务比例 |
| 连接成功率 | ≥ 95% | **≥ 99%** | 局域网设备发现、连接及会话建立成功率 |
| 断线恢复时间 | ≤ 5 s | **≤ 2 s** | 网络短暂中断后重新建立会话所需时间 |
| 应用额外内存占用 | ≤ 200 MB | **≤ 120 MB** | 不包含操作系统及其他应用基础内存占用 |
| 查询阶段 CPU 平均占用 | ≤ 40% | **≤ 25%** | 查询执行期间 SemaLink 进程的平均 CPU 占用 |

## 指标说明

### 1. MVP 合格线

MVP 合格线用于判断系统的基本链路是否已经达到可演示状态，重点验证以下能力：

- 能够发现并连接目标设备；
- 能够选择较可能包含答案的设备；
- 能够返回摘要、段落或表格片段；
- 能够根据证据充分性停止继续传输；
- 在异常网络条件下能够恢复或明确提示失败。

### 2. 竞赛展示目标

竞赛展示目标用于最终测试报告和答辩展示，重点证明 SemaLink 相比完整文件传输具有以下优势：

- 更准确地选择知识所在设备；
- 更快返回第一个有效结果；
- 显著减少跨设备通信量；
- 尽量避免完整原始文件离开本机；
- 在证据充分后及时停止传输；
- 在保证任务正确率的同时降低通信和隐私成本。

## 核心评价口径

SemaLink 最重要的性能结论不应仅表述为“查询速度更快”，而应表述为：

> 在任务成功率基本不下降的情况下，SemaLink 通过设备语义路由、分级证据传输和任务充分性反馈，减少跨设备通信量、缩短首结果延迟，并降低完整原始数据离站比例。
